Generate og-image.jpg

assets/og-image.svg is the canonical social card, but Twitter/X and Facebook will not render SVG in a link preview. This page rasterises the same artwork to a 1200×630 JPEG using the site's real webfonts.

  1. Click the button — the file downloads as og-image.jpg.
  2. Move it into assets/.
  3. In index.html, point og:image and twitter:image at og-image.jpg and set og:image:type to image/jpeg.
