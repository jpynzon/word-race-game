Pick a letter in secret. On reveal, race to type a real English word that fits. Fastest valid word takes the round.

How it works

  1. Create a room

    You get a four-digit code. Share the code or the invite link — no account, no download.

  2. Everyone picks a letter

    In secret. Nobody can see anyone else's letter until the reveal, because the letters never leave the host's memory until then.

  3. Race to a word

    Three-second countdown, then all the letters flip up at once. First valid English word takes the point.

Three ways to play

  • Duel · 2 players

    Your word starts with one player's letter and ends with the other's. M and T gives you moment, market, merit.

  • Round robin · 2–4 players

    Same rule, but two duel each round while everyone else watches the race live. Pairings rotate until everyone has faced everyone.

  • Letter hunt · 3–4 players

    Everyone contributes a letter and the word has to contain all of them, anywhere. B, A, N gives you bandit, brain, abandon.

The host sets how long each race runs and the minimum word length. Words are checked against a real dictionary, with an offline fallback, so nonsense never counts.
